# Screenshot capture plan

No application screenshots are committed yet. Before the first public release, capture the real application rather than using mockups.

The most useful captures would be:

1. `main-connected.png` — the main window connected to an 8×8×8 RGB cube, with normal controls and status visible.
2. `device-audio-setup.png` — **Device & Audio Setup** expanded, showing representative profile, serial-port, and audio-source selections without exposing personal device identifiers.
3. `visualizer-running.jpg` — the application beside the physical cube while an audio-reactive visualizer is active.
4. `linux-desktop.png` — optional Linux desktop view showing the installed launcher and application window.
5. `windows-desktop.png` — optional Windows desktop view showing the application window and original icon.

Use a consistent window size, crop unrelated desktop content, and review images for usernames, device serial numbers, and other private information before committing them. Once images exist, add only the strongest one or two to the root README and keep the remainder here.
